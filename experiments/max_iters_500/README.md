# max_iters_500

- Итераций: 500; сред: 2048; seed: 1; обучение с нуля.
- Финальный mean_reward: 659.86; время обучения: 533 с.
- Последний чекпоинт: `model_499.pt`. Промежуточные чекпоинты в пакет не включены.
- SR не измерен: лимит Colab.
- Исходный TensorBoard-файл сохранён без изменений.

`train.ipynb` — компактная копия обучения; `training.txt` — весь доступный вывод обучения из исходного ноутбука; `training_metrics.csv` — метрики сохранённых итераций (292–499, 208 строк); `experiment.json` — настройки опыта; `config.json` — PPO; `evaluation.json` — статус оценки. Colab обрезал ранний текстовый вывод.

Команда инференса из корня этого пакета в подготовленной Linux/Colab-среде:

```bash
MUJOCO_GL=egl python src/inference.py --checkpoint experiments/max_iters_500/model_499.pt --episodes 10 --seed 42 --record experiments/max_iters_500/evaluation.mp4
```

Исходные ноутбуки всех пяти запусков при инференсе загружали baseline. Неверно отнесённые к этому опыту выводы в эту копию не перенесены. Исходные файлы пользователя оставлены без изменений.
