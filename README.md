# Спринт 3. Эксперименты с обучением PandaPickCube

Пять обучений PPO в Google Colab: baseline, сокращение числа итераций, усиление двух компонент награды и собственный опыт с уменьшением `box_target`.

## Результат

**[Отчёт с таблицами, пятью графиками и выводами](reports/report.md)**

Baseline: SR **8/10** по сохранённому логу. `box_target_strong`: SR **10/10** по повторной оценке, сообщённой пользователем. Для остальных трёх моделей SR не измерен из-за лимитов Colab. Полнота экспериментальной части явно обозначена в отчёте.

## Состав

- `reports/report.md`, `reports/figures/` — отчёт и исходные изображения графиков.
- `experiments/<имя>/` — ноутбук обучения, сохранённая часть текстового лога, метрики доступных итераций, конфигурации, последний чекпоинт, статус и доступные доказательства инференса.
- `results.csv`, `results.json` — сводные результаты; пустые SR обозначают отсутствие измерения, а не нулевой успех.
- `src/` — исходники для инференса и локального обучения; Colab-ноутбуки содержат обучение внутри себя.
- `evaluate_colab.ipynb` — необязательная повторная оценка трёх моделей после восстановления доступа к GPU; обучения в нём нет.
- `sources/` — пользовательские наблюдения в PDF и происхождение файлов с контрольными суммами.

## Как открыть и воспроизвести

Для чтения откройте отчёт на GitHub. Для повторного обучения загрузите `experiments/<имя>/train.ipynb` в Colab, включите GPU, выполните установку, перезапустите сеанс и продолжите с подключения Drive. Число сред — 2048; имена запуска совпадают с исходными, поэтому перед новым обучением используйте новое имя, чтобы не смешать результаты на Drive.

Для оценки готовых моделей откройте `evaluate_colab.ipynb` и следуйте его ячейкам. По умолчанию он использует уже существующие модели в `MyDrive/physicalai_sprint3/logs/`. Для новых сессий понадобится загрузить три файла из `src/`. Чекпоинты также сохранены в этом пакете: если на Drive их больше нет, перенесите папки `experiments/<имя>` в `physicalai_sprint3/logs/<имя>`.

Точный `pip freeze` исходных сессий не предоставлен. Команды установки сохранены для подготовки среды, но не гарантируют совпадение всех версий с исходными запусками. Начальный learning_rate равен 0.001, его адаптивное изменение во время обучения отражено в CSV.

## Подготовка к GitHub

Это готовый каталог файлов, без вложенного `.git`; публикация не выполнялась. Финальные `.pt` включены намеренно (каждый около 4.6 МиБ); промежуточные модели и дубли ZIP не включены. Если копировать пакет внутрь другого репозитория, убедитесь, что его родительский `.gitignore` не исключает `*.pt` и `*.mp4`.

Исходная папка `ap-physicalai-1` не изменялась. Компактные ноутбуки содержат исходный код и последний вывод обучения, но не ошибочные старые оценки baseline. Весь доступный текст обучения вынесен в `training.txt`; ранние строки уже были обрезаны самим Colab. Для полного хода обучения используйте исходные TensorBoard-файлы, где они сохранились.
